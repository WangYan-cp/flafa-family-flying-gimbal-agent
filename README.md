# FLAFA v8.4.0

**FLAFA 家庭飞行云台 AI 辅助拍摄 Agent**

> Public documentation repository · 项目介绍与技术资料公开仓库

FLAFA 面向以家庭内容创作者为核心、同时覆盖普通家庭记录者的持续家庭影像场景。手机仍是主要拍摄设备，飞行云台扩展手机可到达的机位；Agent 结合任务、人物关系、空间、历史经验与实时设备事实生成高层拍摄方案，再由确定性系统、安全模块和硬件适配层完成受控执行。产品以横屏记录为主，同时支持竖屏拍摄。

> 核心边界：LLM 负责语义规划与候选 ID 选择；真实坐标、路径、速度、避障和飞控命令由确定性系统与硬件执行域产生。

## 项目解决什么问题

- 调整镜头和切换机位会中断活动，拍摄者也难以自然参与。
- 手持、自拍和固定支撑难以持续覆盖丰富视角及儿童平视机位。
- 固定与灵活机位需要按活动变化衔接，单纯硬件仍依赖用户持续判断。
- 普通跟踪只回答“目标在哪里”，不能理解“为什么拍、重点是什么、何时调整”。
- 每次拍摄都要重新说明人物、空间和偏好，已确认经验难以在用户控制下复用。
- 专业拍摄参数学习成本高，用户更希望直接表达记录目标。

## 为什么是 Agent

大语言模型是 Agent 的规划能力之一。一次性调用可以生成建议，但不能单独维护用户授权记忆、任务事实、受控候选、确认版本、安全状态和持续运行反馈。FLAFA 将自然语言理解、M1-M6 记忆体系、Context、结构化规划、确定性解析、安全门控、用户确认和 Runtime 组织为可追溯闭环；模型不直接产生坐标、路径、速度、避障或飞控命令。

## v8.4.0 能力

- React + TypeScript AI 拍摄助手；
- Web Speech API 中文语音输入与键盘回退；
- M1-M6 记忆合同、Context Builder、版本化 Context Package 与多轮追问；
- Qwen qwen3.7-max 语义 ShootingPlan；
- Schema、Condition、Safety 与 Task Compiler；
- Runtime 状态、事件、计时、Checkpoint 与回滚；
- Wan wan2.7-image 方案预览与视觉表达；
- 分层评测、完整彩排和 Demo Guard 运行保障。

## 当前阶段

v8.4.0 是面向家庭飞行云台硬件接入的 AI 辅助拍摄 Agent 已开发软件版本。软件主链路及真实模型专项已经形成稳定基线；手机承载、云台、飞控、定位、地图与路径能力正在通过 Hardware Adapter 继续接入。手机是主要成像设备，以横屏拍摄为主并支持竖屏；语音是当前主要自然交互方式，手势属于后续交互适配方向。NFC 是手机与硬件的主要绑定方向，表述为“一碰绑定，快速就绪”。

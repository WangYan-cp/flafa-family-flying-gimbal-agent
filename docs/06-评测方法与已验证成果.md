# Evaluation Framework｜评测方法与已验证成果

FLAFA v8.4.0 | Evaluation Summary｜评测摘要 | 2026-08-18

> FLAFA 的评测不只判断回答“看起来是否合理”，而是同时检查结构合同、候选引用、关键语义、禁用字段、系统安全、运行状态和真实模型表现。

## 1. 分层评测

| 评测层 | 主要对象 | 验证重点 |
|---|---|---|
| Deterministic Regression｜确定性回归 | 合同、状态、幂等、安全和 Visual 协议 | 规则行为可重复、可回归 |
| Real Planner Evaluation｜真实规划模型 | qwen3.7-max 与 P01-P17 | 意图、澄清、边界、结构和安全语义 |
| System Safety Evaluation｜系统安全 | S01-S03 | 低电量、路径阻断、回退与安全链 |
| Visual Model Evaluation｜视觉模型 | Wan 方案预览与拍摄表达 | 人物、空间、活动、媒介和安全表达 |
| ASR Evaluation｜语音识别 | Web Speech 与页面流程 | 权限、连续识别、确认、错误和键盘回退 |
| Full Rehearsal｜完整彩排 | 启动、主链路、追问、Visual、Runtime 和停止 | 锁定环境下的可复现性 |

## 2. 判定原则

- Critical Check 失败即案例失败，不能用总分掩盖。
- live 模式失败不能用确定性回退覆盖。
- 超时、上游错误、合同错误和语义错误分别记录。
- 视觉模型同时进行自动检查和人工复核。
- 修复后运行相关专项与全量回归，防止局部修复造成其他链路退化。

## 3. 锁定成果

| 证据 | 锁定结果 | 结论边界 |
|---|---|---|
| Frontend｜前端 | 11 个测试文件、101 项测试通过，生产构建通过 | 不承诺浏览器语音上游始终低延迟 |
| Backend｜本地服务 | 102 项回归测试通过 | 验证软件合同和确定性行为 |
| Real Planner｜真实规划模型 | P01-P17 最终全量通过 | 适用于锁定测试集，不代表覆盖所有自然语言 |
| System Safety｜系统安全 | S01 5/5、S02 4/4、S03 5/5 | 不替代真实飞行安全认证 |
| Visual｜视觉模型 | Wan 真实调用、合同、人工复核、缓存与回退专项完成 | 预览不承诺与真实相机像素一致 |
| ASR and Rehearsal｜语音与彩排 | 权限、转写、确认、追问补充、键盘回退和完整流程通过 | Web Speech 仍受浏览器与网络影响 |

## 4. 评测价值

这套框架把生成式模型评测与系统工程验证结合起来：模型负责语义能力，合同和规则负责可预测性，安全专项负责阻断风险，完整彩排负责证明端到端链路能够在锁定环境中复现。

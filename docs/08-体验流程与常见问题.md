# Experience Flow and FAQ｜体验流程与常见问题

FLAFA v8.4.0 | Product Experience and FAQ｜产品体验与常见问题 | 2026-08-18

## 1. 一次完整体验

1. 用户进入 AI 拍摄助手，用语音或文字描述拍摄需求。
2. 系统实时显示文字；停止输入或进入静默确认后，用户可以校对需求。
3. 如果缺少空间、时长或关键对象，Agent 发起追问并接收补充。
4. Context Builder 构建任务快照，Qwen 生成高层 ShootingPlan。
5. 方案通过确定性解析、安全审查与用户确认。
6. Wan 可以生成方案预览，帮助用户理解人物、空间、活动和大致构图。
7. 确认后进入 Runtime；用户可以暂停、恢复、取消或结束。
8. 任务完成后，系统按 M1-M6 记忆规则询问是否保存必要的方案、偏好或事件摘要；临时状态不会自动进入长期记忆。

## 2. 常见问题

### FLAFA 是普通自动跟踪吗？

不是。普通跟踪主要关注目标位置；FLAFA 还组织用户目标、人物关系、活动、空间、历史经验、设备事实、受控视点、安全规则和运行变化。

### 大语言模型会直接控制飞行吗？

不会。模型只生成语义 ShootingPlan 和候选 ID 选择。坐标、路径、速度、避障和飞控命令属于确定性系统与硬件执行域。

### 为什么还需要用户确认？

主要人物、空间、模式、风险和长期记忆写入会影响拍摄结果或家庭数据，因此保留用户确认。可逆、低风险、已经授权的微调可以由确定性系统完成。

### 视觉预览是真实相机画面吗？

不是。Wan 预览用于表达方案的人物类型、空间、活动和大致构图，真实画面以现场相机和实际拍摄结果为准。

### 语音识别失败怎么办？

用户可以改用键盘输入。语音是输入适配方式，不改变后续 Context、Planner、Safety 和 Runtime 链路。

### FLAFA 会记住哪些信息？

在用户授权和写入规则允许时，系统可以管理家庭人物关系、家庭空间与拍摄锚点、影像偏好、拍摄事件经验和用户保存的常用方案；当前任务状态只服务本次任务。Context Builder 每次只取任务需要的最小摘要，不会把完整家庭档案交给模型。

### 一次成功拍摄会自动写入长期记忆吗？

不会。临时视点、一次性光照、当前人物位置和临时障碍默认不保存。事件经验、偏好变化和常用方案需要满足写入规则并由用户确认；用户可以查看、纠正、停用或删除长期记忆。

### 手机如何与飞行云台连接？

产品方向采用 NFC 作为主要绑定方式：触碰识别与绑定、建立连接、完成权限与状态检查、进入就绪，再由用户确认开始。“一碰绑定，快速就绪”不代表触碰后自动起飞。当前 Stage 6 资料以 Agent 软件为主，真实硬件链路仍按 Hardware Adapter 边界继续接入。

### 当前已经完成到什么程度？

v8.4.0 已经完成交互、Context、Qwen 规划、确定性校验与安全、Runtime、Wan 视觉表达、ASR、专项评测和运行保障的软件闭环。真实云台、飞控、相机、定位与路径能力正在按 Hardware Adapter 边界继续接入。

### 软件通过是否代表已经完成真实飞行认证？

不代表。真实飞行、定位、避障、续航、噪声、长期稳定性和量产指标需要独立硬件联合验证。
